# Lagring av treningsøkter

Opprett årsmapper ved første økt, for eksempel `2026/`. Hver trening får én Markdown-fil kopiert fra [øktmalen](../maler/okt.md).

Filnavn: `AAAA-MM-DD-onsdag-tema.md` eller `AAAA-MM-DD-sondag-tema.md`. Bruk korte temanavn med bindestrek, for eksempel `pasning-og-bevegelse`. Økt-ID er `G2017-AAAA-MM-DD-onsdag` eller `G2017-AAAA-MM-DD-sondag`. Ved flere økter samme dag får ID og filnavn et løpenummer.

Øktfilen inneholder både opprinnelig plan, faktisk gjennomføring og Tiim-lenke. En ny gjennomføring får ny fil og referanse til tidligere økt. Behold historisk innhold ved gjenbruk.

Periodeplaner kan lagres i samme årsmappe som `periode-AAAA-MM-DD-til-AAAA-MM-DD.md`, kopiert fra [periodemalen](../maler/periodeplan.md).

Ingen konkrete økter er opprettet ennå.
