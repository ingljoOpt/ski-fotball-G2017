# Øvelsesbank for G2017

Bruk [Tiims bibliotek](https://tiim.no/okter-og-ovelser) med filter 8–9 år i 2026. Øvelsene under er kontrollert mot kildesidene 4. november 2026. Beskrivelsene er korte sammendrag; les kilden ved detaljplanlegging. Ingen av øvelsene er ennå registrert som gjennomført av laget.

## Lokale tilpasninger

Bruk kilde-ID og variantnavn, for eksempel `T003-liten-bane`, og skriv konkret hva som endres. En lokal variant arver ikke automatisk kildens organisering, ballbehov eller aldersmerking. Egen aktivitet uten en bestemt kilde får ID `L001`, `L002` og så videre.

Ved nye oppføringer registreres tittel, kildelenke, aldersmerking, kontrolldato, tema, gruppestørrelse, aktive baller og mål. Tall som ikke står i Tiim merkes som lokale planvalg. Faktisk bruk og erfaring føres i øktfilen og historikken, slik at banken ikke blir et konkurrerende øktregister.
